# 1. typeof

typeof gets the type of a variable.

Example 1
```
let name = "Saravanan";

type NameType = typeof name;
```
Here,
```
type NameType = string;

Because name is a string.
```

# Example 2
```
let age = 25;

type AgeType = typeof age;

Equivalent to:

type AgeType = number;
Example 3 (Object)
const student = {
    name: "Ravi",
    age: 25,
    course: "React"
};

type StudentType = typeof student;

Now StudentType becomes:

type StudentType = {
    name: string;
    age: number;
    course: string;
}
```
So you don't have to write the type manually.
