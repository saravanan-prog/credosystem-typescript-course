### 1. Classes

A class is a blueprint for creating objects.
```
class Person {
    name: string;
    age: number;
}

const person = new Person();
person.name = "Saravanan";
person.age = 25;


```

### 2. Constructors
A constructor initializes an object when it's created.
```
class Person {
    name: string;
    age: number;

    constructor(name: string, age: number) {
        this.name = name;
        this.age = age;
    }
}

const person = new Person("Saravanan", 25);
console.log(person.name);
console.log(person.age);

```

### 3. Access Modifiers

Access modifiers control who can access class properties.

```
    public
    private
    protected
```

#### public
```
 class Person {
    public name: string;

    constructor(name: string) {
        this.name = name;
    }
}

const p = new Person("John");

console.log(p.name);
```

#### private

```
class BankAccount {
    private balance = 1000;

    showBalance() {
        console.log(this.balance);
    }
}

const account = new BankAccount();

account.showBalance();

```
#### protected

Accessible inside the class and subclasses, but not outside
```
class Animal {
    protected sound = "Some sound";
}

class Dog extends Animal {
    bark() {
        console.log(this.sound);
    }
}

const dog = new Dog();

dog.bark();


```
