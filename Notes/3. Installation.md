# Installation Procedure
### Step 1: Verify Node.js and npm Installation

- Open the Command Prompt or Terminal and execute the following commands
- If version numbers are displayed, Node.js and npm have been installed successfully.

```
    node -v
    npm -v
```




### Step 2: Install TypeScript

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Install TypeScript globally using the following command:
```
npm install -g typescript
```
### Step 3: Verify the Installation

- Check whether TypeScript has been installed successfully by running:
- The command displays the installed TypeScript version.
```
tsc --version
```


### Step 4: Create a TypeScript File

- Create a file named app.ts and write the following code:
```      
let name: string = "Saravanan";
console.log(name);
```
### Step 5: Compile the TypeScript File

-  Use the TypeScript compiler to convert the TypeScript file into JavaScript:
-  After compilation, a file named app.js will be generated.
```
tsc app.ts
```


Step 6: Execute the JavaScript File

- Run the generated JavaScript file using Node.js:
```
node app.js
Output
Saravanan
```
