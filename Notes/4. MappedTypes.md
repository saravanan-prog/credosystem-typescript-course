# Mapped Types

- A Mapped Type creates a new type by transforming the properties of an existing type.

Example
```
type Student = {
    name: string;
    age: number;
    course: string;
};
```
- Suppose we want every property to become optional.
```
type OptionalStudent = {
    [K in keyof Student]?: Student[K];
};
```
Result:
```
type OptionalStudent = {
    name?: string;
    age?: number;
    course?: string;
}
```
Usage
```
const student: OptionalStudent = {
    name: "Ravi"
};
```
No need to provide all properties.

Another Example

Make everything readonly.
```
type ReadOnlyStudent = {
    readonly [K in keyof Student]: Student[K];
};
```
Now
```
const student: ReadOnlyStudent = {
    name: "Ravi",
    age: 20,
    course: "React"
};

// student.age = 25; ❌ Error
```
