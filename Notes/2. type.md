# type

- TypeScript, think of it as a way to create a `custom name for a type`.

```
type User = {
  name: string;
  age: number;
};

let user: User = {
  name: "John",
  age: 25,
};

```






### 1. Union Types (|)

A value can be one type or another.
```
type ID = string | number;

let userId: ID;

userId = 101;      // ✅
userId = "A101";   // ✅
```

### 2. Intersection Types (&)

A value must satisfy all types.

```
type Person = {
  name: string;
};

type Employee = {
  salary: number;
};

type Staff = Person & Employee;

Result:

{
  name: string;
  salary: number;
}

```
### 3. Combining Unions and Intersections

```
type Admin = {
  role: "admin";
};

type User = {
  name: string;
};

type AdminUser = User & Admin;

Must have both:

const a: AdminUser = {
  name: "John",
  role: "admin"
};

```
### 4. Literal Types

Only specific values are allowed.
```
type Status = "loading" | "success" | "error";
```
let state: Status = "success"; // ✅
### 5. Function Types

```
type Add = (a: number, b: number) => number;

const add: Add = (a, b) => a + b;

```

### 6. Arrays + Objects

```
type User = {
  id: number;
  name: string;
};

type Users = User[];
```

### 7. Nested Types

```
type Address = {
  city: string;
  country: string;
};

type User = {
  name: string;
  address: Address;
};
```
