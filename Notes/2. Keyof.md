# keyof

keyof extracts all property names (keys) of a type.

Example
```
type Student = {
    name: string;
    age: number;
    course: string;
};
```
Now
```
type StudentKeys = keyof Student;
```
becomes
```
type StudentKeys = "name" | "age" | "course";
```
These are the valid keys.

Example
```
type Student = {
    name: string;
    age: number;
};

let key: keyof Student;

key = "name"; // ✅
key = "age";  // ✅

// key = "salary"; // ❌ Error
```
