# Why is TypeScript Used?

### 1. Type Safety

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;TypeScript `checks data types during development` and helps prevent common programming errors.

```
    function add(a: number, b: number): number {
        return a + b;
    }

    add(10, 20);   // Correct
    add(10, "20"); // Error

```

### 2. Better Code Quality

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Type annotations make `code easier to read, understand`, and maintain, especially in large projects.

```
let username: string = "Saravanan";
let age: number = 25;
```



### 3. Improved Developer Productivity

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;Modern code editors provide:

- Auto-completion
- Error highlighting
- Intelligent suggestions
- Easy refactoring

&nbsp;&nbsp;&nbsp;&nbsp;This helps developers write code faster and with fewer mistakes.


### 4. Supports Object-Oriented Programming

&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;&nbsp;TypeScript includes features such as:

- Classes
- Interfaces
- Inheritance
- Access modifiers (public, private, protected)
