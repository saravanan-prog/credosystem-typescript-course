# 1. TypeScript Fundamentals

#### TypeScript

- `TypeScript` is an open-source programming language developed by `Microsoft`.
- It is a superset of JavaScript
- which means` all valid JavaScript code` is also valid `TypeScript code`.

TypeScript adds:

```
    Static typing
    Interfaces
    Classes
    Generics
    Better tooling and IDE support
```

#### Example - JavaScript
```
    let age = 25;
    age = "Hello"; // No error
```
#### Example - TypeScript
```        
    let age: number = 25;
    age = "Hello"; // Error
```
