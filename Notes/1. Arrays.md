### Arrays

An array is a collection of values stored in a single variable.

#### Syntax

```
let arrayName: type[] = [value1, value2, value3];
```
##### Example 1 Array of String

```
let skills: string[] = ["JavaScript", "TypeScript", "React"];
console.log(skills[0]);

```

##### Example 2 - Array of Numbers
```
let marks: number[] = [85, 90, 95];

console.log(marks)
```

##### Example 3 -  Mixed Arrays Using Union Types

```
let data: (string | number)[] = ["Saravanan", 25, "Developer"];
["Saravanan", 25, "Developer"]

```
