# Default Parameters in TypeScript

- Default parameters allow you to assign a default value to a function parameter.

- If no value is passed when the function is called, the default value is used.

#### Syntax
```
function functionName(parameter: type = defaultValue) {
  // code
}

```

#### Example 1

```
function greet(name: string = "Guest") {
  return `Hello ${name}`;
}

console.log(greet("Saravanan"));
console.log(greet());
```
#### Example 2
```
function calculatePrice(price: number, tax: number = 18) {
  return price + (price * tax) / 100;
}

console.log(calculatePrice(1000));
console.log(calculatePrice(1000, 10));

```
