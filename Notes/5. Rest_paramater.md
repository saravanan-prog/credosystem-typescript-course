# Rest Parameters in TypeScript
- Rest parameters allow a function to accept any number of arguments and store them in a single array.

- A rest parameter is defined using three dots (...) before the parameter name.

#### Syntax
```
function functionName(...parameter: type[]) {
  // code
}
```


#### Example 1 
```
function sum(...numbers: number[]): number {
  return numbers.reduce((total, num) => total + num, 0);
}


console.log(sum(10, 20));
console.log(sum(10, 20, 30, 40));

```

#### Example 2

```
function studentDetails(name: string, ...skills: string[]) {
  console.log("Name:", name);
  console.log("Skills:", skills);
}



studentDetails(
  "Saravanan",
  "JavaScript",
  "TypeScript",
  "React"
);

```
