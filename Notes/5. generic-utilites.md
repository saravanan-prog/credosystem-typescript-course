# Utility Types

TypeScript provides built-in utility types.

### 1. Partial

Makes every property optional.
```
type Student = {
    name: string;
    age: number;
    course: string;
};
```
Without Partial
```
const student: Student = {
    name: "Ravi"
};

❌ Error
```
With Partial
```
const student: Partial<Student> = {
    name: "Ravi"
};
```
Equivalent to
```
{
    name?: string;
    age?: number;
    course?: string;
}
```
Common use:

Updating an object

function updateStudent(student: Partial<Student>) {}
### 2. Pick
```
Select only specific properties.

type Student = {
    name: string;
    age: number;
    course: string;
};
type StudentName = Pick<Student, "name">;

Result

{
    name: string;
}
```
Pick multiple
```
type BasicInfo = Pick<Student, "name" | "course">;
```
Result
```
{
    name: string;
    course: string;
}
```
### 3. Omit

Remove specific properties.
```
type Student = {
    name: string;
    age: number;
    course: string;
};
```
Remove age
```
type StudentWithoutAge =
    Omit<Student, "age">;

Result
```
{
    name: string;
    course: string;
}
```
Remove multiple


type Data =
Omit<Student,"age" | "course">

Result

{
    name:string
}
```
### 4. Record

Creates an object type where keys are one type and values are another.

Syntax
```
Record<Keys, ValueType>
```
Example
```
type Students = Record<string, number>;

Means

{
    [key:string]: number;
}
```
Usage
```
const marks: Record<string, number> = {
    Ravi: 95,
    Kumar: 85,
    John: 90
};
```
Another Example
```
type Employee = {
    id:number;
    name:string;
}
const employees:
Record<number, Employee> = {

    1:{
        id:1,
        name:"John"
    },

    2:{
        id:2,
        name:"David"
    }

};
```
Access
```
console.log(employees[1].name);

Output

John
Real-world Example
type User = {
    id:number;
    name:string;
    email:string;
}
```
Creating a user
```
const user: User = {
    id:1,
    name:"Ravi",
    email:"abc@gmail.com"
}
```
Updating user
```
const updateUser:
Partial<User> = {

    email:"new@gmail.com"

};
```
Returning only public data
```
type PublicUser =
Pick<User,"name" | "email">
```
Removing sensitive data
```
type UserWithoutEmail =
Omit<User,"email">
```
Dictionary
```
const users:
Record<number,User> = {

    1:user

};
```
