### 1. string

- The `string` type is used to store `text values`.
- Example

```
let name: string = "Saravanan";
console.log(name);

Output
Saravanan
```

### 2. number

- The `number` type is used to store numeric values such as `integers and decimal` numbers.

Example
```
let age: number = 25;
let salary: number = 25000.50;

console.log(age);
console.log(salary);

Output
25
25000.5

```

### 3. boolean

- The `boolean` type is used to store logical values: `true or false`.
- Example
```
let isLoggedIn: boolean = true;
console.log(isLoggedIn);

Output
true

```
### 4. null

- The `null` type represents an intentional `absence` of a value.
```
Example

let data: null = null;
console.log(data);

Output
null
```
### 5. undefined

The `undefined` type indicates that a variable has been declared but has not been assigned a value.

Example
```
    let value: undefined = undefined;
    console.log(value);

    Output
    undefined
```
### 6. any

- The `any` type allows a variable to hold values of `any data type`.
- `Type checking is disabled` for variables declared with any.
- The any type should be avoided whenever possible because it removes TypeScript's type safety features.

```
Example

let result: any = 100;
result = "Hello";
result = true;
console.log(result);

Output
true

```

### 7. unknown

The `unknown` type can store `any value`, but type checking must be performed before using the value.

Example
```
let input: unknown = "TypeScript";

if (typeof input === "string") {
    console.log(input.toUpperCase());
}

Output
TYPESCRIPT
```

### 8. void

The `void type` is mainly used as a return type for functions that `do not return any value`.

Example

```
function displayMessage(): void {
    console.log("Welcome to TypeScript");
}

Output
Welcome to TypeScript

```
