# Objects
- An object is a collection of key-value pairs.

#### Syntax

```
let objectName: {
  property1: type;
  property2: type;
};
```

##### Example 1 - Simple object

```
    let user: {
      name: string;
      age: number;

    } = {
        name: "Saravanan",
        age: 25
    };



console.log(user.name);
console.log(user.age);
```

##### Example 2  - Nested Object

```
let employee: {
  name: string;
  address: {
    city: string;
    state: string;
  };
} = {
  name: "Saravanan",
  address: {
    city: "Chennai",
    state: "Tamil Nadu"
  }
};

```

##### Example 2  - Array of Objects

```
    let students: {
        id: number;
        name: string;
    }[] = [
        { id: 1, name: "John" },
        { id: 2, name: "Peter" },
        { id: 3, name: "Saravanan" }
    ];


    console.log(students[2].name);

```
